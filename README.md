# Portfolio | Data Science

¡Bienvenido a mi portfolio profesional! Soy **Sergi**, Data Scientist. Comencé mi trayectoria profesional en el mundo de la automoción, estudié un grado superior y trabajé durante dos años como mecánico en Citroën. Mientras trabajaba, mi curiosidad por los datos y la tecnología me llevó a estudiar un grado universitario en Ciencia de Datos.

Desde entonces, he dedicado mi tiempo no solo a aprender, sino también a desarrollar proyectos que combinan mi pasión por la Ciencia de Datos con otros campos como el desarrollo web.

Entre mis proyectos destaco trabajos de limpieza, transformación y visualización de datos utilizando herramientas como Tableau, Power BI, Python, R o MongoDB. También he explorado APIs, web scraping y diseño de bases de datos. Este porfolio es un ejemplo de mi incursión en el desarrollo web, construido con herramientas como Astro y Tailwind.

Actualmente, me estoy especializándome en el análisis de datos geoespaciales, inteligencia artificial soberana y arquitectura de datos. Este proyecto no solo muestra mi trabajo, sino que sirve como base técnica para el despliegue de soluciones de observación terrestre.

## Stack Tecnológico

Este portfolio ha sido construido con un enfoque en la velocidad, la eficiencia y el diseño moderno:

*   **Core:** [Astro.build](https://astro.build/)
*   **Estilos:** Tailwind CSS
*   **Gestor de Paquetes:** `pnpm`

## Áreas de Especialización

El portfolio destaca mis habilidades en cinco pilares clave para el sector aeroespacial y tecnológico:

1.  **Geospatial Data Science:** Procesamiento de imágenes Sentinel-2, uso de Google Earth Engine (GEE) e índices de vegetación (NDVI).
2.  **Advanced Analytics & Big Data:** Manipulación de grandes volúmenes de datos con Python.
3.  **AI & Local LLMs (RAG):** Implementación de arquitecturas de generación aumentada por recuperación (RAG) utilizando modelos locales (Ollama/LM Studio).
4.  **Database Engineering:** Gestión de bases de datos espaciales con PostgreSQL + PostGIS.
5.  **Visualization & BI:** Dashboards interactivos con Streamlit, Tableau y Power BI.
